# DB-02 × Collection — private Steam v1.26.2 exact-name overlay

`/collection` can optionally take the owner's local **DB-01 native-key v2 private ZIP** *after* decoding a user-selected save. Files never leave the browser. The ZIP is handled in a separate one-shot Web Worker and the main thread receives only Item IDs, current officially/source-verified localized names, and verified native item class. This never changes the local Collection owned/missing workspace and never uploads or persists original ZIP or save bytes.

Owner-private ZIP: `Dreamwish Wand/Development/Sources/DB-01 ... /db01-steam-v1262-sqlite-typescript-native-key-v2-private.zip` (the original audited 10,226,751-byte package). An independently audited manifest SHA-256 is pinned in `src/lib/collection/private-db01-release.mjs`, **not read from the user-selected ZIP**. The original private audit records `wand.db01.private-native-key-migration@1`, status `PASS`, 33,627 partial definitions, 3,657 current exact names, 560 ZIP entries (557 shards), 256 ID buckets, and no publication authorization. The ZIP reader never extracts or reads the 72.6MB SQLite entry, locale/category shards, but reads only `private-shards/manifest.json` and the requested `private-shards/id/XX.json` and SHA-verified `private-shards/historical/XX.json` paths. The historical path is an explicitly source-qualified candidate, never a current exact name. The existing `src/lib/items/index.ts` client SHA-verifies every ID shard and validates domain, source, category, name status and current source format. ZIP parser applies path restrictions, central/local header consistency, raw-DEFLATE bounds and CRC32 verification.

**Labels and evidence constraints**:
- A non-null DB-01 `names[locale]` is source-exact for **Steam 1.26.2**; `names.en` is a *verified English fallback* only if that locale lacks an exact value. Missing exact labels stay missing. In an **explicitly opt-in** alternate display, `historical_prefix_crc_correlated_unverified_current` labels from Steam 1.26.1 may be shown as reference candidates; they are NEVER promoted to 1.26.2 verified names, and original baseline version and evidence status are retained.
- The saved P1G JSON reports schema 643, **not an attested game build/version**; therefore source exactness is never proof that these names correspond to the saved file's game version. The UI explicitly discloses this distinction.
- The public Collection default is still Nintendo Switch 1.25.0; its historical labels and images remain reference-only. **No source-matched current artwork is available**, so the historical image control remains opt-in and OFF by default.
- A saved display reference does not prove Collection ownership, purchase history, current store offer, price, remaining stock, rights, entitlements or an official Save Codec round-trip.
- The file remains PRIVATE. Never place it or its shards, SQLite, actual item data, full decoded save, or player-specific Item IDs in GitHub/Pages.

Tests: `node --test tests/collection-db01-{zip,name-view}.test.mjs` and `node --experimental-strip-types --test tests/collection-db01-core.check.mjs` (the second directly invokes the existing DB-01 TypeScript reader); Collection CI must pass `npm test`, `npm run check` and `npm run build`. The owner-private ZIP is verified only in local audit, not included as a CI fixture.
