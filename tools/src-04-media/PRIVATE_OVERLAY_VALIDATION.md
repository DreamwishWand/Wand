## Reusable read-only QA

Run the standalone `verify_private_overlay.py` with a ZIP generated by the private exporter; optionally supply the same version's original SRC-01 item bytes. The source SHA-256 must match the manifest. The data remains on the local machine.

```sh
python tools/src-04-media/verify_private_overlay.py /private/private-media-overlay-latest.zip \
  --source-items /private/source-items/items.jsonl \
  --expected-items 13202 --expected-guids 9542 \
  --manifest-sha 3e85aee5b34d7f20c7384fb5b2d83c21c33be83ec9f8ac3fffa807f72e98f5a0 \
  --map-sha 80772618dad8ff8e26a581119c95cfb5a122499fd7252f9c163d9fe8da0a2cad
```

For future updates, pass **that version's** expected counts and optional hashes instead of hardcoding 1.26.2 compatibility. Exact SHA and GUID/path ID matches determine identity.
