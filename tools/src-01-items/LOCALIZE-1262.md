# Steam v1.26.2 — verified eight-language item display names

`localize1262.py` reads the previous `items.jsonl` and `manifest.json` from `steam1262.py` and the **original local game** `LocDB_{en-US,fr,it,de,es,ja,zh-CN,pt-BR}.zip` files. It requires Python 3.10+ standard library only, does not need a local Git repository, and does not modify either the game files or previous generated files.

The format evidence was obtained from the owner-private `format-probe.json` generated by `probe_formats.py`. In eight locales, the inspected `ActivityItem.locbin`, `Furniture.locbin`, `Clothing.locbin`, `Trimming.locbin` samples contain protobuf wire-type 2 top-level field 1 entries; each entry has UTF-8 key field 1 and value field 2. Verified sample pairs include `Amethyst_DisplayName` -> English "Amethyst", Japanese "アメジスト", French "Améthyste". The native item field 2 provides the matching key prefix. This is evidence for an **exact category-specific key join**, not heuristic translation.

Example from PowerShell (replace no paths if using the standard Steam and Desktop layout):

```powershell
py -3 localize1262.py --game "C:\Program Files (x86)\Steam\steamapps\common\Disney Dreamlight Valley" --source "$env:USERPROFILE\Desktop\DreamwishWand\SRC-01 ITEMS\Steam-v1.26.2" --out "$env:USERPROFILE\Desktop\DreamwishWand\SRC-01 ITEMS\Steam-v1.26.2"
```

Four new output files appear alongside the five original files:

- `items-localized.jsonl`: native Item ID / icon GUID / source data and verified per-language names; missing exact matches remain null.
- `localization-manifest.json`: SHA-256 source provenance for every locale archive and decoded category data.
- `localization-report.json`: per-locale and per-category matched/missing counts and eight-language complete count.
- `localization-unresolved.json`: precise remaining Item IDs per locale/category.

The tool verifies the prior source manifest and `items.jsonl` checksum, four Steam v1.26.2 itemlist digests, and installed game version. It validates every consumed localization entry and rejects conflicting duplicate keys or corrupt/unknown wire structures. The generated data is not automatically published or deployed. Upload **only the four new files** to `Dreamwish Wand / Development / Sources / SRC-01 ITEMS` in Google Drive. Subsequent analysis should use that folder as the persistent data source.

The remaining 35 itemlist schemas, quest/item boundaries, subcategories, DLC, world/universe data, and cross-platform collection reconciliation are separate work; do not infer them from name matches.
